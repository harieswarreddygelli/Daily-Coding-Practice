## Matrix Representation

In Python, a matrix can be represented using a list of lists.

```python
matrix = [
    [1, 2, 3],
    [4, 5, 6]
]
```

Each inner list represents a row.

## Important Concept

Matrix elements are accessed using:

```python
matrix[i][j]
```

Where:

* `i` represents the row index
* `j` represents the column index

Example:

```python
matrix[0][1]
```

Output:

```text
2
```
